# C Language Lexical Analyzer

A lexical analyzer written in C that scans source code and identifies different types of tokens. It recognizes keywords, identifiers, operators, literals, comments, separators, and punctuation, while also detecting lexical errors.

## Features

- Identifies C language keywords
- Detects identifiers
- Recognizes operators
- Handles integer, string, and character literals
- Detects comments
- Identifies separators and punctuation
- Reports lexical errors

## Technologies

- C Programming Language
- Lexical Analysis
- File Handling
- String Processing
